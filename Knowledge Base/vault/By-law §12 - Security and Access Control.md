# By-law §12 - Security and Access Control

## Summary
Controls vehicle ingress/egress, visitor authentication, vehicle wheel-clamping, and physical security parameters throughout the residential development.

## Key Regulations

| Security Parameter | Standard / Protocol | Penalty / Charge |
|---|---|---|
| Resident Vehicle Transponder | 1 free transponder per registered unit; max 2 | $80 replacement fee for lost transponder |
| Unauthorized / Illegal Parking | Parked in non-designated lots or visitor lot overnight | $100 wheel-clamp release fee |
| Late-Night Visitor Clearance | Mandatory guardhouse registration past 11:00 PM | Guard intercom verification with resident |
| Gantry Tailgating | Prohibited at entry and exit barriers | Barrier arm damage claim: $850 replacement |
